# 🛍️ Sticker Web

A responsive front-end sticker store website built with **HTML, CSS, and JavaScript**.

## 📌 About the Project

Sticker Web is a modern and responsive online sticker shop where users can browse different sticker collections through a clean and user-friendly interface.

## ✨ Features

* 🛍️ Responsive sticker store design
* 🎨 Modern and clean user interface
* 📱 Mobile-friendly layout
* 🔎 Easy navigation
* 🖼️ Sticker collection showcase
* ⚡ Smooth interactions using JavaScript

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 📂 Project Structure

```text
sticker.web/
├── index.html
├── style.css
├── script.js
├── images/
└── README.md
```

## 🎯 Purpose

This project was created to practice **front-end web development, responsive design, HTML, CSS, and JavaScript** while building a real-world e-commerce-style website.
